The problem

Agent failures are hard to debug once work moves across agents.

Prompt or policy?

A bad answer might come from the instruction, the policy lookup, or the final response formatting.

Routing or handoff?

Swarm failures often happen when one agent passes incomplete state to the next agent.

Fix or regression?

Without repeatable cases, a better prompt can quietly break another category of task.
